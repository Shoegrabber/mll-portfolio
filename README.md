# mll-portfolio

Professional portfolio for **Ben Fynes-Clinton** — EAL/D and multilingual learner specialist, Perth WA.

Served by GitHub Pages from `main` at the repository root.

```
index.html                      the portfolio page
assets/                         portrait and document previews
evidence/                       linked source documents
  principles-assessment-scaffolding.html
```

## Notes

- The page carries `<meta name="robots" content="noindex, nofollow">`. The repository is public because GitHub Pages requires it on a free account; the page is meant to be reached by a link given out deliberately, not found through search.
- **No student names or identifying data appear in this repository.** Every file was scanned against the full class roster in both body text and PDF metadata before publication. Documents that did carry student data are held outside this repository and are not published.
- The ILP system walkthrough on the page uses **fictional student data** and is labelled as such.
